# CookieClickerTools (CCTools)

Cookie Clicker（クッキークリッカー）のプレイをより快適にし、面倒な作業を自動化するためのブラウザ拡張スクリプト（ブックマークレット）です。
ゲーム内のオプション画面に完全に統合された専用の設定UIを備え、各機能のON/OFFや詳細な数値をゲーム内から直接カスタマイズできます。

## インストール・使い方

本ツールはローカルサーバー経由でスクリプトを読み込む形式となっています。

1. リポジトリ内のファイルを任意のフォルダ（例: `d:\products\CookieClickerTools\`）に配置します。
2. そのフォルダをルートとして、ローカルWebサーバー（ポート8080）を立ち上げます。
   * 例: `python -m http.server 8080` や、Node.jsの `http-server` などを使用。
3. ブラウザで新しいブックマークを作成し、URL（リンク先）に `bookmarklet.js` の内容をコピーして保存します。
4. Cookie Clickerのゲーム画面を開き、作成したブックマークをクリックするとツールが起動します。
5. ゲーム上部メニューの「オプション」を開くと、一番下に「CCTools Settings」が追加されています。

## 実装されている機能

機能はゲーム内設定画面にて以下のカテゴリに分類されています。

### 自動系
放置プレイを強力にサポートする自動化スクリプト群です。

* **大クッキー自動クリック (`autoclicker.js`)**:
  指定したCPS（1秒あたりのクリック数）で大クッキーを自動クリックします。
* **ゴールデンクッキー・トナカイ自動クリック (`autogolden.js`)**:
  画面に出現した黄金クッキーやトナカイを即座に自動クリックします。
* **フォーチュンクッキー自動クリック (`autofortune.js`)**:
  ニュースティッカーに流れてくるフォーチュンクッキーを自動で獲得します。
* **株式市場の自動売買 (`automarket.js`)**:
  銀行ミニゲームにおいて、相場を監視し最適なタイミングで株の自動売買を行います。
* **Godzamokの自動発動 (`autogodzamok.js`)**:
  神殿ミニゲームにおいて、クリックバフやCpSバフが重なった瞬間に指定した施設（初期はカーソルと農場）を自動で「100個売却→即購入」し、強力なバフを発動します。
* **農場の自動化 (`autogarden.js`)**:
  ガーデンミニゲームを完全自動化します。
  * 雑草の自動駆除
  * 未解放の種が成熟した瞬間の自動収穫
  * 寿命が尽きて枯れる直前の自動収穫
  * 自動作付（Auto-Plant）: 指定した種を効率的なレイアウト（1種交配、2種交配、JQBなど）で自動配置
  * 自動交配（Auto-Crossbreed）: 未取得の種をリストの上から自動精査し、最適な親を自動で作付
  * 土壌の自動切り替え: 成長中は「肥料(Fertilizer)」、成熟後は交配率を上げるため「木屑(Woodchips)」に自動変更

### 表示系
隠しデータや今後の予測を画面上にわかりやすく表示します。

* **黄金クッキー効果予測の表示 (`goldenoverlay.js`)**:
  魔法で出現した黄金クッキーの「確定している中身」を、クッキーのアイコン上に直接テキストでオーバーレイ表示します。
* **Force the Hand of Fate 予測表示 (`fthof.js`)**:
  魔法塔のミニゲーム内に、次から10回分の「Force the Hand of Fate」で出現する黄金クッキーの効果一覧テーブルを表示します。
* **バフ・デバフの残り時間表示 (`bufftimer.js`)**:
  画面下部に並ぶバフアイコンに、正確な残り時間（秒、または 分/時フォーマット）を表示します。GodzamokなどのFPS低下ハック中も現実時間に合わせて正確にカウントダウンします。
* **黄金クッキー出現予測ゲージ (`goldenbar.js`)**:
  画面左のクッキー情報の下に、黄金クッキーが出現するまでの「待機時間（絶対に出ない）」と「警告時間（出る可能性がある）」を2段階のプログレスバーと文字で可視化します。凍結状態にも対応しています。

### 補助系
プレイの利便性を向上させるサポート機能です。

* **施設の50個購入機能 (`buy50.js`)**:
  右上の店舗の「買う(Buy)/売る(Sell)」設定に、10と100の間の「50」ボタンを追加します。レイアウト崩れを起こさず、スマートに配置されます。
* **虫の一括駆除 (`wrinkler.js`)**:
  キーボードの「W」キーを押すことで、大クッキーに群がっているしわしわ虫（Wrinkler）を安全に一括駆除できます。

### チート系
ゲームバランスを著しく壊す可能性のある強力な機能です。

* **虫の希少種変換 (`wrinkler.js`)**:
  キーボードの「S」キーを押すことで、現在出現している通常のしわしわ虫を、吸収還元率が極めて高い希少種（Shiny Wrinkler）に全変換します。

## 注意事項
* クッキークリッカーのアップデートによって、内部関数の仕様が変わるとツールが正常に動作しなくなる可能性があります。
* 自動化やチート機能を使用するとゲーム本来の楽しみが損なわれる場合があります。ご自身のプレイスタイルに合わせて設定をON/OFFしてご利用ください。
